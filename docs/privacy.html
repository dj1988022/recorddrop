Privacy Policy

Last updated: August 26, 2026

What we collect

RecordDrop collects the following data only to auto-generate bug-report context:

  • The URL of the page being recorded
  • Browser user-agent string
  • Viewport and screen dimensions
  • Page title
  • Recording timestamp
  • Console error logs (if any)

How we use it

This data is embedded into the screen-recording share link and displayed alongside the video to help developers understand the environment where a bug was captured. We do not use this data for advertising, profiling, or sell it to third parties.

Data storage

Recorded videos and their associated context are stored on api.recorddrop.site (or your own server if self-hosted). Users may request deletion by opening a GitHub issue.

Contact

Privacy questions: GitHub Issues or hello@recorddrop.site
