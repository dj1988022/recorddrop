# Privacy Policy for RecordDrop

Last updated: August 26, 2026

## Data We Collect

RecordDrop collects the following data solely for the purpose of auto-generating bug report context:

- **URL** of the page being recorded
- **Browser user agent** string
- **Viewport and screen dimensions**
- **Page title**
- **Timestamp** of recording
- **Console error logs** (if any)

## How We Use Data

This data is embedded into the screen recording share link and displayed alongside the video to help developers understand the environment in which a bug was captured. No data is used for advertising, profiling, or sold to third parties.

## Data Storage

Recorded videos and associated context are stored on the server (api.recorddrop.site). Users can request deletion by opening a GitHub issue.
