# RecordDrop

Screen recording for developers. Press `Alt+R` to record, auto-insert to GitHub Issues.

## Features

- **Alt+R** to start recording on any page
- **Auto-insert** video link + environment context into GitHub comment boxes
- **Self-hosted** backend — your videos, your server
- **MP4 output** — native playback on any device
- **No login required** — open the extension and start recording

## Install

Coming soon to Chrome Web Store.

For developers (manual load):
1. Download this repo
2. Open `chrome://extensions/` → Enable Developer mode
3. Click "Load unpacked" → Select the `recorddrop-extension` folder

## Usage

1. Open any GitHub Issue page
2. Press `Alt+R` (or click the 🎥 button in the comment toolbar)
3. Select "Entire Screen" → Share
4. Stop recording → Video link automatically inserted into the comment box
